# Dashboard wordmark

`giravanz-wordmark.jpg` is the unmodified Giravanz Kitakyushu club wordmark
published by Iizuka City on its official friendly-town page:
https://www.city.iizuka.lg.jp/soshiki/17/2429.html

Image source: https://www.city.iizuka.lg.jp/uploaded/image/2039.jpg

The wordmark belongs to Giravanz Kitakyushu and is used to identify the club
on this unofficial supporter dashboard. It is not a distributable typeface.
