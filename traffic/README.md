# GitHub アクセス履歴（管理用）

コード公開ページへの閲覧数・日別訪問者数・クローン数を毎日取得し、暗号化した履歴と日本語のグラフ・一覧を作成します。公開アプリへのアクセス解析とは別です。サイト本体にはリンクやスクリプトを追加しません。

## 初回設定（アカウント所有者が実施）

1. GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens でトークンを作成します。対象を `rockiemydog/j3-elo-simulator` のみに限定し、Repository permissions の **Administration: Read-only** を付与します。Contents の書き込み権限は不要です。有効期限が切れる前に更新してください。
2. リポジトリの Settings → Secrets and variables → Actions → New repository secret に以下の2件を登録します。値をチャット、コード、Issue、PR本文に貼り付けないでください。

   | Secret名 | 内容 |
   |---|---|
   | `TRAFFIC_READ_TOKEN` | 上記のトークン |
   | `TRAFFIC_REPORT_PASSWORD` | ランダム生成した十分に強いパスワード（最低16文字。パスワード管理アプリ等で保管） |

3. Actions → **Private repository traffic report** → Run workflow を実行します。
4. 実行結果下部の Artifacts から **private-traffic-report** をダウンロードして展開し、`report.html` をブラウザーで開き、パスワードを入力します。スマートフォンでローカルHTMLを実行できないプレビューアの場合は、MacのSafari等を使用してください。

mainに反映後、毎日日本時間09:37ごろに実行予定です。GitHub側の実行遅延・停止はあり得ます。未設定の場合は「初期設定待ち」と表示し、数値を作りません。

## 保存とプライバシー

- `traffic-history` という専用の独立ブランチへ、AES-256-GCM / PBKDF2-SHA256（600,000回）で暗号化した `archive.json` と `report.html` のみを保存します。mainの結果データ・予測・公開処理は変更しません。履歴は同じ日付を上書き訂正し、重複加算しません。
- **暗号文と復号画面のソース自体は公開リポジトリ上で誰でも取得できます。** パスワードを知る人は集計を読めます。個別ユーザー認証ではありません。弱いパスワードは避けてください。平文の数値、トークン、パスワードをリポジトリ・Actionsログ・成果物へ保存しません。
- HTMLはすべて自己完結し、外部スクリプト・外部通信を使用しません。ブラウザーに入力するのは復号パスワードだけです。APIトークンはブラウザーに渡しません。復号したデータはブラウザーの永続ストレージに保存しません。
- パスワードを変更すると既存履歴は復号できず処理が停止します。変更する場合は、旧パスワードで履歴を復号して新パスワードで再暗号化する移行作業が必要です。旧パスワードを失うと過去履歴は復元できません。
- Actionsの成果物は30日で削除されますが、専用ブランチの暗号化された全履歴は残ります。最新版の `report.html` はブランチからもダウンロードできます。

## 数字の読み方

- 過去14日のAPIデータを毎回取り込み、重なる日を置き換えます。GitHubが提供しない導入前の古いデータは復元できません。未取得日はゼロにせず「—」にします。長期の取得漏れはそのまま欠測になります。
- 上段の「直近14日間」はAPIが返す期間集計です。日別ユニーク数の合計ではありません。同じ人が複数日に訪れるため、日別ユニーク数を合計して月間ユニーク数にはできません。
- 日付はUTC基準。日本時間では当日09:00〜翌日09:00です。日本時間の日別集計へ正確に組み替えるための時間別データは取得できません。取得日時は日本時間で表示します。当日分は途中値です。
- 参照元と人気ページは各取得時点の直近14日間・上位10件です。重なる14日間の数値を足し合わせません。日別スナップショットは暗号化履歴内に保存しますが、画面には最新のものを表示します。
- 訪問者の氏名・IPアドレスや各人のアクセス時刻は取得できません。自分以外の人間だけを厳密に抽出する仕組みではありません。クローンには自動処理が含まれる可能性があり、閲覧数と同一視しません。
